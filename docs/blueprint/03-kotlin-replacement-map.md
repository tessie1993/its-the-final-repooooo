# 3 · Kotlin replacement map (all 290 files)

No Kotlin was imported. This table is the inventory of what the Kotlin did and where each piece
of behaviour goes. To read an original file, open it in the source repo at
`tessie1993/visuals-its-the-final-repooooo@bd70915`, under
`geode-app-85491c2b76b26cf45c77f2f7fcda6b2f0d8855bd/<path>`.

**Target key:**

| Tag | Meaning |
|---|---|
| **UI** | Flutter widget/screen (Dart) |
| **DART** | Pure Dart logic: model, store, service or state. No widgets |
| **C++** | Moves into the native core (new C++ module, see doc 5 §5.4) |
| **FFI** | Dart FFI binding over the existing C ABI |
| **SHIM** | An Android entry point Flutter/C++ cannot host. See decision D1 in doc 6 |
| **DROP** | Not needed: Flutter, the new design or a package covers it |
| **📦 DATA** | The file holds catalog data that must be **extracted to a JSON asset** before the Kotlin is gone for good. Do this in phase 0 |

LOC = original line count.
